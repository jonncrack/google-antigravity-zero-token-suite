# Filosofía de Consumo de Tokens (Eficiencia Máxima)

- **Prioridad de Bajo Consumo:** Al ofrecer soluciones, proponer integraciones o sugerir herramientas, SIEMPRE debes priorizar la ruta que consuma la menor cantidad de tokens posible.
- **Evitar Herramientas Pesadas Innecesarias:** Si existe una alternativa simple (como pedirle al usuario que copie y pegue un texto o usar un script headless ligero) en lugar de utilizar herramientas de alto consumo de contexto (como el comando `/browser`, análisis visual de imágenes o scraping pesado del DOM), debes recomendar la alternativa simple primero.
- **Enrutamiento Automático de Archivos (Activación Proactiva a 0 Tokens):** Aunque el usuario no mencione explícitamente el comando o no etiquete la skill (`/`), siempre que proporcione o mencione un archivo, DEBES aplicar de forma automática y estricta el protocolo de su skill optimizadora correspondiente:
  1. 🎙️ **Audios (`.mp3`, `.wav`, `.m4a`, `.aac`, `.flac`, `.ogg`, `.opus`) o YouTube:** Activar `audio-transcription-optimizer`. Transcribir por defecto en local con `faster-whisper` a 0 tokens de API. Para coros con música fuerte o notas de voz cantadas, escalar a `gemini-3.5-transcribe` vía API. Para YouTube sin subtítulos, usar Agentic Video en la nube. NUNCA llamar `view_file` sobre binarios de audio en el chat para evitar el error 400.
  2. 🎬 **Videos (`.mp4`, `.mov`, `.mkv`, `.webm`) o grabaciones largas:** Activar `video-analysis-optimizer`. Para UI/bugs locales, extraer fotogramas con FFmpeg (`fps=1`) a 0 tokens y limpiar temporales. Para videos largos (>15 min) o conferencias en la nube, invocar el modo agéntico de Gemini (`processing="agentic"`) para lograr 88% de ahorro de tokens sin descargas a disco.
  3. 📄 **Documentos PDF (`.pdf`):** Activar `pdf-analysis-optimizer`. Extraer texto y estructura localmente con scripts headless (`pypdf`, `pdfplumber`, `pymupdf`). Para libros y manuales extensos, aplicar el protocolo "Distill-to-Skill".
  4. 📊 **Hojas de Cálculo y Office (`.xlsx`, `.xls`, `.csv`, `.docx`, `.pptx`):** Activar `office-files-optimizer`. Analizar y transformar datos mediante scripts locales (`pandas`, `openpyxl`, `python-docx`) sin volcar archivos crudos en el chat.
  5. 🌐 **Código HTML y Dumps Web (`.html`, `.htm`, `.php` o snippets DOM):** Activar `html-parser-optimizer`. Procesar con scripts headless locales (`BeautifulSoup4`, `html2text`) para eliminar scripts, estilos y SVG, extrayendo únicamente selectores de automatización o texto semántico a 0 tokens de basura.
  6. 📦 **Paquetes y Archivos Comprimidos (`.zip`, `.tar.gz`, `.rar`, `.7z`):** Activar `archive-inspector-optimizer`. Inspeccionar estructura interna en memoria (`zipfile`/`tarfile`) y extraer quirúrgicamente solo archivos relevantes a `scratch/extracted/` sin desempacar masivamente al workspace.
  7. 🖼️ **Imágenes con Texto Escaneado / OCR (`.png`, `.jpg`, `.jpeg`, `.webp` de recibos, actas, exámenes):** Activar `ocr-image-optimizer`. Extraer texto y cifras localmente con Tesseract OCR y Pillow a 0 tokens de visión de API.
  8. 🚀 **Automatización Web en Segundo Plano:** Activar `web-background-automation`. Ejecutar flujos repetitivos y scraping en modo headless con Playwright y BeautifulSoup a 0 tokens de UI.
